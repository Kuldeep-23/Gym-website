# Gym-website

A static fitness website project featuring workout challenges, exercise guidance, and diet/nutrition pages.

## Project structure

- `css/main.css` - shared styling
- `js/main.js` - shared client-side interactions
- `assets/images/` - active image assets used by pages
- `assets/originals/` - source image backups
- `archive/` - archived large project zip files

## Run locally

1. Clone/download this repository.
2. Open `/home/runner/work/Gym-website/Gym-website/index.html` in a browser.
   - Optional (recommended): serve with a local server:
     - Python: `python -m http.server 8080`
     - Then open `http://localhost:8080/index.html`

## Pages

- `index.html`
- `login.html`
- `register.html`
- `challenges.html`
- `diet.html`
- `nutrients.html`
- `exercise.html`
- `background.html`
